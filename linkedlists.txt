What is the difference between a linked list and a dynamic array?

- A linked list stores data in nodes located randomly in memory and connects them using pointers, 
while a dynamic array stores elements in contiguous memory, 
enabling faster access via index-based calculation.

What is one of the strengths of a linked list?

- Linked lists allow fast insertion and removal at the beginning and end of the list without
shifting elements or worrying about capacity.

What is one of the drawbacks of a linked list?

-Accessing specific elements is slower, because you must traverse the list node by node instead
of jumping directly to an index like in arrays. ⏳
